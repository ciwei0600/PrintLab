# 结构、切片与打印交接

在进入正式工程、切片、打印或实物验收时读取。路径均相对实际 PrintLab 工作台；命令参数以当前 `./Harness/bin/printlab --help` 和子命令帮助为准。

## 结构与配合

- 先核实真实外观已获准确版本确认；早期布局只证明空间可行性，不代替正式工程验收。
- 组件尺寸保留来源、测量基准和可信状态。区分孔边距离与孔中心距、主体深度与拨杆高度、运动行程与焊脚设计余量。未经实测的尺寸不得标成已确认。
- 检查真实接口、紧固件可达性、装入路径、拆装、线缆弯曲、开关完整行程、前后盖接缝、壁厚及打印方向相关的强度。检查真实支撑接触区和重心，不能以外观“看起来稳”推定站立稳定。
- 小试模与正式件复用相同接口参数。试模未打印或未装配时只报告数字验证结果；实际配合仍待确认。见 `Context/cad-master-design.md`。
- 输出源文件、装配/剖视、零件图、关键尺寸和公差、检查结果及未决项。影响外形的结构变更重新走外观内审和用户确认。

## 材料与实际切片

- 重新读取真实设备、喷嘴、打印板、供料路线、装槽耗材和库存来源；保留已有 H2D 等设备配置，不用模板设备覆盖。未知材料或供料映射不猜测。
- 使用本机官方 Bambu Studio 中匹配实际机型的配置。检查工具版本和可用能力，不能用通用网格导出冒充已切片工程。
- 对需要比较的方案实际切片，查看各层、悬空、薄壁、支撑接触、接缝、材料切换及多盘安排，记录实际估算时间与用量。配色和重要质量/耗时取舍沿用用户有效选择；需要新增决定时给出具体选项。
- 读取 `Context/x2d-final-review.md` 和 `Templates/Project/Review/x2d-final-review.md` 的适用项；文件名含 X2D 不代表实际设备就是 X2D。某文件不存在时定位当前等效流程，不伪造验证。
- 区分可编辑 CAD、几何 3MF、Studio 工程和实际切片包，保存对应源模型、配置、盘号及哈希。未经真实切片检查，不报告打印时间、材料用量为已验证结果。

## 授权和单次发送

执行前读取 `Context/official-studio-dispatch.md`、`docs/PRINTING.md` 及当前任务记录；这里只给出保持一致的原则，不绕过现有门禁。

1. 把具体版本、文件、盘号、设备、材料映射、预计时间/用量和检查结果准备成可审阅任务，再取得本次必要授权。
2. 检查实时设备与已有任务、当次清板事实和批准有效性。现行流程为 30 分钟清板/批准校验；以当前工作台规则执行，过期不能补写虚假时间。
3. `approve / submit / reconcile` 使用同一任务记录。仅预检通过不等于已授权发送，也不等于打印已开始。
4. 官方 Studio 在预约有效窗口内发送一次并读回唯一任务标识。无回执、超时或状态不明，先对账；不得因不确定而重复点击或重复发送。
5. 每盘单独检查任务适用性，上一盘结束需实体取件和清板。切换文件、设备或材料时重新核对绑定，不能复用不适用的批准。

## 实物反馈

分别记录提交、设备接受、实际出料、首层、机器完成与用户验收。没有实际证据不代填。检查成形、尺寸、配合、稳定性、表面、后处理、强度和功能；电气等未验证部分明确列出，外壳验收不自动证明整机安全。

失败反馈关联具体版本、材料和配置；回到受影响阶段，新版本保留旧件与原因。库存估算、设备报告和实称余量分开记录，百分比不能推断为实际满卷。
